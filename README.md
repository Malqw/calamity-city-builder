# Билдер отрядов Calamity City — свой сайт без Artifact

Этот вариант билдера не зависит от claude.ai: сайт — обычный статический
`index.html`, данные (оружие/снаряжение/способности/роли) хранятся в вашей
Google Таблице и правятся прямо в её ячейках, а сохранённые отряды игроков
лежат в отдельной вкладке той же таблицы. Ссылку можно скинуть кому угодно,
никаких аккаунтов claude.ai не требуется.

Схема: **index.html** (сайт, отдаёте на GitHub Pages) → ходит по сети за
данными и за отрядами в → **Google Apps Script** (маленький бесплатный
бэкенд, живёт «внутри» вашей таблицы) → который читает/пишет в →
**вкладки Google Таблицы** (это и есть админка — правите циферки прямо там).

Всё бесплатно, отдельного хостинга/сервера заводить не нужно.

---

## Шаг 1. Таблица и бэкенд (Google Apps Script)

1. Откройте [sheets.google.com](https://sheets.google.com) → **Создать таблицу**.
   Назовите её как угодно, например «Calamity City — данные».
2. В меню таблицы: **Расширения → Apps Script**. Откроется редактор кода
   в отдельной вкладке.
3. В редакторе слева уже есть файл `Code.gs` с примером кода — выделите его
   содержимое целиком и удалите, затем вставьте туда **всё содержимое**
   файла [`apps-script/Code.gs`](apps-script/Code.gs) из этого проекта.
4. Сохраните (значок дискеты сверху или Ctrl/Cmd+S). Проект можно назвать
   как угодно, например «Calamity City API».
5. Разверните как веб-приложение: кнопка **Развернуть → Новое развёртывание**.
   - Тип: **Веб-приложение**.
   - Описание: любое.
   - «Выполнять как»: **Я (ваш аккаунт)**.
   - «У кого есть доступ»: **Все (Anyone)** — это важно, иначе сайт не
     сможет достучаться до данных с чужих компьютеров.
   - Нажмите **Развернуть**. Google спросит разрешения — это нормально,
     разрешите (скрипт работает только с этой вашей таблицей).
6. После развёртывания появится **URL веб-приложения** вида
   `https://script.google.com/macros/s/XXXXXXX/exec` — скопируйте его
   целиком, он понадобится в шаге 3.
7. Вернитесь в саму таблицу (вкладка в браузере) и обновите страницу
   (F5). Сверху появится новое меню **Calamity City** — откройте его и
   нажмите **«Создать/обновить вкладки с начальными данными»**. Один раз
   выполнится — появятся вкладки «Оружие», «Снаряжение», «Способности»,
   «Архетипы», «Роли», «Спецправила», «Глоссарий», «Отряды», уже заполненные
   текущими значениями из билдера.

Готово — это и есть ваша админка. Открывайте нужную вкладку и правьте
ячейки: стоимость оружия, текст способности, лимиты ролей и т.д. Изменения
подхватятся сайтом при следующей загрузке страницы (без пересборки и без
кода). Можно и добавлять новые строки — новое оружие, новую способность —
просто придумайте новый `id` (латиницей, без пробелов) и заполните
остальные колонки по образцу соседних строк.

**Не меняйте существующий `id` у строки**, если у отряда, собранного на
сайте, уже может быть выбран этот предмет/способность — билдер хранит
именно id. Менять название, стоимость, текст — можно свободно.

---

## Шаг 2. Проверьте API

Откройте в браузере тот самый URL из шага 6 (можно прямо так, без
параметров) — должен открыться JSON с данными оружия/снаряжения и т.д.
Если вместо этого ошибка доступа — вернитесь в «Развернуть» и проверьте,
что доступ выставлен на «Все».

---

## Шаг 3. Подключите сайт к таблице

1. Откройте `index.html` из этого проекта в любом текстовом редакторе.
2. Найдите строку (в начале блока `<script>`, ищите `API_URL`):
   ```js
   var API_URL = '';
   ```
3. Впишите туда URL из шага 6, например:
   ```js
   var API_URL = 'https://script.google.com/macros/s/XXXXXXX/exec';
   ```
4. Сохраните файл.

Пока `API_URL` пуст, сайт всё равно открывается и билдером можно
пользоваться — но на «встроенной» копии данных (той, что была на момент
скачивания файла), без сохранения отрядов и без правок из таблицы. Это и
есть офлайн-режим на случай, если бэкенд недоступен.

---

## Шаг 4. Выложите сайт на GitHub Pages

1. Если ещё нет аккаунта — заведите на [github.com](https://github.com)
   (бесплатно).
2. Создайте новый репозиторий (**New repository**), например
   `calamity-city-builder`. Можно публичный — там нет ничего секретного
   (сам код сайта открыт для всех, кому вы дадите на него ссылку, а
   игровые данные и так должны быть видны всем игрокам).
3. Загрузите в репозиторий файл `index.html` из этого проекта (кнопка
   **Add file → Upload files** на странице репозитория, перетащите файл,
   Commit changes). Файл `apps-script/Code.gs` заливать необязательно —
   он уже вставлен в саму таблицу на шаге 1, это просто его резервная копия.
4. В репозитории: **Settings → Pages**. В разделе «Build and deployment»
   выберите источник **Deploy from a branch**, ветка `main`, папка `/root`
   → **Save**.
5. Через минуту-две там же появится ссылка вида
   `https://<ваш-логин>.github.io/calamity-city-builder/` — это и есть
   ссылка на билдер, её можно скидывать всем.

Если позже поправите `index.html` (например, обновите `API_URL` или
попросите ещё что-то изменить) — просто загрузите новую версию файла тем
же способом (**Add file → Upload files**, с заменой) или через commit,
если работаете через git. Ссылка останется той же.

## Как это работает для игроков

- **Вкладка «Билдер»** — как раньше: выбор архетипа, добавление бойцов,
  прокачка параметров, оружие/снаряжение/способности, подсчёт стоимости.
- **Вкладка «Мои отряды»** — вместо входа через аккаунт теперь просто
  просят придумать **имя и код доступа** (любые, хоть «Аня» и «1234») —
  это не настоящая регистрация, а простой способ отделить чужие отряды
  от своих. Под одной и той же парой имя+код отряды видны и
  редактируются; тот, кто не знает вашу пару, не увидит и не удалит ваши
  отряды. Это осознанно лёгкий уровень защиты, подходящий для игры в
  кругу друзей — не используйте для кода доступа пароли, которые
  применяете где-то ещё.
- Правки в Google Таблице видят все сразу (при следующей загрузке
  страницы) — отдельной «публикации» изменений не требуется.

## Ограничения и на что обратить внимание

- **Это не защищённая система.** Код доступа хранится в таблице открытым
  текстом, и любой, кто получит доступ на просмотр самой Google Таблицы
  («Отряды»), сможет прочитать чужие пары имя/код. Для тестовой игры в
  кругу друзей это нормально; для чего-то большего — нужен другой уровень
  авторизации.
- **Бесплатные лимиты Google Apps Script**: около 20000 обращений в день
  на один аккаунт — для тестовой группы это с огромным запасом.
- Не давайте вкладке **«Отряды»** в таблице простой доступ на редактирование
  всем подряд — это единственная вкладка, которую имеет смысл держать
  скрытой от игроков (Формат → Скрыть лист), хотя напрямую с сайта в неё
  никто, кроме как через API, не пишет.
- Если переименуете вкладки в таблице (например, «Оружие» на что-то
  другое) — скрипт перестанет их находить. Если нужно переименовать,
  поправьте соответствующую константу в начале `Code.gs`
  (`SHEET_WEAPONS` и т.д.) и переразверните скрипт (**Развернуть →
  Управление развёртываниями → значок карандаша → Развернуть** — URL
  останется тем же).
